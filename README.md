# 🐍 Pokédex Python

Uma aplicação desenvolvida em **Python** utilizando a **PokéAPI** para consultar informações de qualquer Pokémon pelo **nome** ou **número da Pokédex**.

## 📸 Demonstração

> Adicione o print abaixo na pasta `assets` do projeto e altere o caminho se necessário.

![Pokédex](assets/pokedex.png)

## ✨ Funcionalidades

- 🔍 Pesquisa por **nome** ou **número** do Pokémon;
- 🖼️ Exibição da imagem (sprite) oficial;
- 📋 Informações do Pokémon:
  - Nome
  - Número
  - Altura
  - Peso
  - Tipo(s)
  - Habilidade(s)
- ❌ Tratamento para Pokémon inexistentes;
- 🖥️ Interface gráfica desenvolvida com **Tkinter**.

## 🛠️ Tecnologias

- Python 3
- Tkinter
- Requests
- Pillow (PIL)
- PokéAPI

## 🚀 Como executar

Clone o repositório:

```bash
git clone https://github.com/SEU_USUARIO/pokedex-python.git
```

Entre na pasta:

```bash
cd pokedex-python
```

Instale as dependências:

```bash
pip install -r requirements.txt
```

Execute o projeto:

```bash
python main.py
```
